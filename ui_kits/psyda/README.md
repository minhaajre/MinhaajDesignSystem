# Psyda UI Kit

Recreates the editorial redesign of **psyda.org** — an analytics agency website with a warm parchment palette, editorial typography, and scroll-linked animations.

## Design System
- Fonts: Cormorant Garamond (display), DM Sans (UI), Inter (body)
- Colors: Warm parchment #F7F3EC, copper accent #8C7355
- Style: Square edges, no rounded corners, fill-sweep buttons, word-reveal on scroll

## Files
- `index.html` — Full interactive prototype (nav + hero + sections + contact + footer)
- `Nav.jsx` — Fixed frosted nav with scroll state
- `Hero.jsx` — 3-pillar scroll-linked hero
- `ChapterSection.jsx` — Chapter grid with sticky sidebar + editorial list
- `Footer.jsx` — Minimal footer with logo

## Usage
Open `index.html` directly in a browser — no build step required.
