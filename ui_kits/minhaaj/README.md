# Minhaaj.com UI Kit

Recreates **minhaaj.com** — Minhaaj Rehman's personal brand site. Currently on Squarespace, planned migration to Next.js. Editorial, personal, coaching-focused.

## Design System
- Same warm parchment palette and Cormorant Garamond as Psyda (sibling brand)
- Content: Bio, Excellence Accelerator coaching program, philanthropy, contact
- Tone: First-person, authoritative, warm

## Files
- `index.html` — Full interactive prototype
- `HeroSection.jsx` — Biography hero with tagline
- `AcceleratorSection.jsx` — Coaching program + pricing tiers
- `Footer.jsx` — Contact + social links

## Notes
- No logo asset available for minhaaj.com specifically (uses Squarespace)
- Photography placeholders used for portrait
