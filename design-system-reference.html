Section 1

About This Design System

This is the single source of truth for the Minhaaj brand ecosystem — four distinct visual identities united by a shared design philosophy: editorial warmth, scholarly precision, calm confidence.

Who this is for: Designers, front-end developers, content creators, and agency partners building across Psyda, Minhaaj.com, CCIAF, and IbnArbi properties.

How to use this document: Each section covers one design domain (color, typography, spacing, etc.) with brand-specific sub-sections. Use the sidebar to navigate. Brand tabs let you toggle between palettes within a domain.

Designer's Note This reference consolidates what was previously scattered across tokens/, components/, patterns/, and preview/ files. The token CSS files remain the source of truth for implementation; this page explains why and when to use each token.

Design Philosophy

A beautifully typeset academic journal, crossed with a luxury magazine layout. Nothing shouts. Everything is precise.

Core Principles

  • Editorial first. Every design decision supports a reading experience. Generous line-height, tight tracking on small caps, max-width prose columns.
  • Single accent color. Each brand has exactly one accent color (copper or gold). Emphasis comes from weight and spacing, not color variety.
  • Warmth without sentimentality. All colors are earth-toned. Nothing is cool, blue-shifted, or cold. Archival warmth.
  • Depth from tone, not shadows. Psyda uses background tone shifts instead of box shadows. CCIAF uses subtle dual-layer shadows. IbnArbi uses glass blur.
  • Scholarly precision. Typography is intentional — every size has a semantic role, every weight has a purpose. Nothing is decorative.

CCIAF only

Typography

Three distinct typography systems across the ecosystem, each optimized for its brand's content type. All fonts loaded from Google Fonts — no self-hosted files.

Three-Font System

Psyda and Minhaaj.com use three distinct typefaces — one per role (display, UI, body). This provides maximum editorial control at the cost of an extra font load.

RoleFontWeightsUsage
DisplayCormorant Garamond300, 400, 500, 600 + italicMajor headings, pull quotes, chapter numbers, editorial figures, nav brand
UIDM Sans300, 400, 500Nav links, labels, eyebrows, metadata, buttons (all uppercase contexts)
BodyInter300, 400, 500Paragraphs, prose, body copy, long-form reading
Design rationale: Using Inter for body text (instead of a serif) keeps long-form reading comfortable at smaller sizes. Cormorant Garamond provides editorial drama at large sizes. DM Sans keeps UI elements crisp and technical.

Scroll Reveal Patterns

General rule: Reveal on scroll should feel natural, not aggressive. Use fade-up (translateY + opacity) at 0.7–0.9s. Avoid scale, rotate, or bounce reveals.

CCIAF Fade-up (`.r`)

.r { opacity: 0; transform: translateY(22px); transition: opacity .7s ease, transform .7s ease; }
.r.on { opacity: 1; transform: none; }

Triggered by IntersectionObserver at threshold 0.1. Used on all page content sections.

Reduced Motion

All brands respect prefers-reduced-motion: reduce. When active, every animation and transition is killed — durations set to 0.01ms, scroll-behavior set to auto.

Required. This is not optional. Every page must include the reduced motion media query. Test with your OS accessibility settings before shipping.

Section 9

Accessibility Standards

Color & Contrast

  • All text/background combinations meet WCAG AA minimum (4.5:1 body, 3:1 large text)
  • Gold accent is decorative only — never the sole conveyor of meaning
  • Selection background: --accent (copper/gold) with --white text
  • Focus-visible outlines: 2px solid var(--gold), 3px offset, 2px radius

Focus & Keyboard

  • Skip link on every page: positioned off-screen, slides to top:0 on focus
  • Theme toggle: role="switch", aria-checked
  • Mobile menu toggle: aria-controls referencing menu id, aria-expanded managed via .open class
  • All interactive elements have visible focus-visible outlines
  • Tab order matches visual layout order

Reduced Motion

Required on every page. The full media query must be present:
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: .01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
    transition-duration: .01ms !important;
  }
}

This kills all animations, transitions, and smooth scrolling — including the toggle theme transitions. Elements must appear in their final visual state when reduced motion is active.
